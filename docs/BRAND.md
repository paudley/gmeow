# Gmeow Brand

## Positioning

Gmeow is local Gmail intelligence for agents. It should read as technical, local-first,
and automation-ready rather than as a hosted email product.

## Tagline

Local Gmail intelligence for agents.

## Repository Description

Local Gmail intelligence for agents, MCP, and REST automation.

## Family System

Gmeow belongs to a family of `g` + cat-sound repositories, such as `gmeow`
for mail and `gpurr` for Drive. Keep the family recognizable by reusing the
same black cat silhouette and swapping the service object held by the cat.
For sibling repos, preserve the `cat-head-core` SVG group and replace the
`service-envelope` group with the relevant service object.

## Logo Assets

- `docs/gmeow-logo.svg` is the canonical Gmeow logo.
- `docs/social-preview.svg` is the editable GitHub sharing-card source.
- `docs/social-preview.png` is the rendered 1280x640 GitHub social preview.

Use the SVG for README, social-preview, icon, and card placements. The README
uses the raw GitHub URL so the logo also renders on PyPI when `README.md`
becomes the package long description.

GitHub repository social previews are uploaded in repository settings. Use
`docs/social-preview.png` for that upload.
