# Migration Revisions

This directory holds the committed Alembic revisions for the Gmeow schema. Each file is a
single migration generated by `alembic revision --autogenerate -m "..."` and reviewed before
landing.

## Conventions

- Revisions are immutable once merged. Roll forward with a new revision rather than amending an
  existing one.
- Add new revisions through the Alembic CLI invoked from the repo root so they pick up the
  configured `gmeow` schema and naming convention.
- Revisions that change graph / vector index definitions should include forward and reverse
  operations so test rebuilds stay symmetric.
